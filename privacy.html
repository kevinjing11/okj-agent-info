OKJ Intelligence

Privacy Notice

Last updated September 9, 2026.

Purpose and scope

OKJ Intelligence is a private desktop agent used by the owner of the OKJ artist project. It runs locally on the owner’s Mac and is not a public app or sign-up service.

Information the agent handles

The agent processes local music files and related catalog, audio-analysis, planning, contact, and draft records chosen by its owner. These persistent records are stored locally on the owner’s computer.

If the owner chooses to authorize Gmail, the agent requests only the Google gmail.readonly scope for the dedicated OKJ mailbox. It reads recent messages and associated mail information to create local records and briefs. It does not request permission to send, edit, delete, label, or otherwise modify Gmail data.

If the owner enables OpenAI features, bounded content used to prepare private owner briefs or draft text may be sent to OpenAI. If the owner enables Brave Search, public search queries and public result data may be obtained for research leads. Those connections are optional.

Use and sharing

Gmail data is used only for the local, owner-facing features described here: organizing recent mail and producing private briefs. It is not sold, used for advertising, or provided to data brokers. The agent has no email or social-message sending function.

Gmail data remains in the owner’s local application state unless the owner separately chooses to use an optional feature that submits bounded content to OpenAI. Public-search data is handled as public research material. This site itself does not collect visitor analytics, account registrations, or contact-form submissions.

Retention, deletion, and revocation

The owner controls the local application state and can disable or remove local records from the computer. Gmail access can be revoked at any time through Google Account permissions. Revoking access stops future Gmail access; it does not by itself remove records already stored locally. For questions about local data or deletion, contact okjartist@gmail.com.

Google API Services

OKJ Intelligence’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
